# Оксамит — шоколадне ательє

Концепт головної сторінки інтернет-магазину авторського шоколаду (проєкт для портфоліо).
Увесь сайт — один файл `index.html`: HTML, CSS і JS усередині, без збірки й залежностей.

## Що на сторінці

- **Hero** з ефектом рваного паперу: крізь отвір видно фото, під час скролу отвір розширюється
- **Колекція**: 6 цукерок, фільтр «Темний / Молочний / Білий / Горіхові»
- **Конструктор коробки** на 6, 9 або 16 цукерок: цукерка лягає в наступну вільну комірку, «Заповнити випадково», листівка з живим прев'ю, вибір дати доставки, підсумок; «Додати в кошик» активна лише для повної коробки
- **Кошик** у хедері з лічильником коробок (зберігається в браузері)
- **Адвент-календар** на 24 віконця (до 1 грудня працює в демо-режимі)
- **Форма для корпоративних клієнтів** (концепт: дані нікуди не надсилаються)
- **Відгуки** — приклади, позначені як концепт

Адаптив від 320 до 1920 px, підтримка `prefers-reduced-motion`, справжні `button` і `label`, контраст тексту ≥ 4.5:1.

## Фото

Усі фото підключені з [Pexels](https://www.pexels.com) за прямими посиланнями (безкоштовна ліцензія Pexels).
Якщо фото не завантажилось, на його місці показується какао-градієнт.
Щоб замінити фото, знайдіть у `index.html` посилання `images.pexels.com` і підставте свої.

## Публікація на GitHub

1. Створіть новий репозиторій на [github.com/new](https://github.com/new), наприклад `oksamyt`.
2. Завантажте файли одним із двох способів:
   - **через браузер:** у репозиторії натисніть **Add file → Upload files**, перетягніть `index.html` і `README.md`, потім **Commit changes**;
   - **через термінал:**
     ```bash
     git init
     git add index.html README.md
     git commit -m "Оксамит: перша версія"
     git branch -M main
     git remote add origin https://github.com/<ваш-логін>/oksamyt.git
     git push -u origin main
     ```

## Деплой на Vercel

1. Увійдіть на [vercel.com](https://vercel.com) через GitHub.
2. **Add New → Project**, оберіть репозиторій `oksamyt` і натисніть **Import**.
3. **Framework Preset:** `Other`. Build Command і Output Directory лишіть порожніми.
4. Натисніть **Deploy** — за хвилину сайт буде доступний за адресою `oksamyt.vercel.app` (або схожою).

Після кожного `git push` у гілку `main` Vercel оновлює сайт автоматично.

### Альтернатива: GitHub Pages

У репозиторії: **Settings → Pages → Source: Deploy from a branch → main / (root) → Save**.
Сайт з'явиться за адресою `https://<ваш-логін>.github.io/oksamyt/`.

## Локальний перегляд

Відкрийте `index.html` у браузері. Для фото й шрифтів потрібен інтернет.
